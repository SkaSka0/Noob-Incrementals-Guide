# Game Progression Guide

Kumpulan guide progres untuk game ini, disusun ulang dari catatan pribadi supaya lebih mudah dibaca dan diikuti orang lain. Repo ini mengikuti struktur 3 section yang ada di dalam game: **Prestige Guides**, **Other Info**, dan **Runes Information**.

## 📖 Cara Pakai

- Baru main? Mulai dari [`prestige-guides/00-prestige-0-1.md`](prestige-guides/00-prestige-0-1.md) dan ikuti urut sampai prestige kamu sekarang.
- Bingung istilah? Cek [`GLOSSARY.md`](GLOSSARY.md) dulu.
- Butuh info soal sistem tertentu (bukan urutan prestige) seperti Sand, Auras, atau Hacker Points? Lihat [`other-info/`](other-info/).
- Mau tahu detail rune per realm? Lihat [`runes-information/`](runes-information/).
