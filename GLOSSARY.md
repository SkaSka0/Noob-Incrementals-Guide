# Glossary

Kumpulan istilah, singkatan, dan angka yang sering muncul di guide-guide dalam repo ini. Kalau nemu istilah baru waktu nulis guide, tambahkan di sini juga supaya nggak perlu dijelaskan ulang di tiap file.

## Singkatan Angka (Big Number Notation)

Game ini pakai notasi angka besar ala idle game. Urutannya:

| Singkatan | Nama | Nilai |
|---|---|---|
| K | Thousand | 10^3 |
| M | Million | 10^6 |
| B | Billion | 10^9 |
| T | Trillion | 10^12 |
| Qd | Quadrillion | 10^15 |
| Qt | Quintillion | 10^18 |
| Sx | Sextillion | 10^21 |
| Sp | Septillion | 10^24 |
| Oc | Octillion | 10^27 |
| No | Nonillion | 10^30 |
| Dc | Decillion | 10^33 |
| Uvt | Undecillion | 10^36 |
| Vt | (bagian dari notasi lanjutan, biasanya muncul digabung seperti "qdvt") | — |

> Catatan: notasi gabungan seperti **qdvt** atau **100qdvt** adalah cara singkat menuliskan angka besar bertingkat (mirip notasi ilmiah kombinasi). Kalau menemukan notasi baru yang belum ada di tabel ini, tambahkan sumbernya.

## Istilah Umum Gameplay

| Istilah | Penjelasan |
|---|---|
| **dps** | Damage Per Second — total damage yang dihasilkan per detik |
| **rps** | (Rune/Resource) Per Second — laju perolehan resource tertentu per detik |
| **AFK farm** | Membiarkan karakter grind otomatis tanpa perlu aktif main |
| **Rank** | Level/tier progres untuk sistem tertentu (mis. Sand Rank) |
| **Rune Bulk** | Multiplier/jumlah rune yang didapat per aktivitas rune |
| **Rune Speed** | Kecepatan mendapatkan rune |
| **Milestone** | Target/ambang tertentu yang memberi reward saat tercapai |
| **Noobinial** | Sejenis karakter/unit rune tertentu (Sphinx, Anubis, Pharaoh, dll termasuk kategori ini) |
| **Transcend** | Sistem reset/upgrade lanjutan pada noobs untuk kekuatan lebih tinggi |
| **Gamepass** | Item berbayar yang memberi keuntungan permanen |

## Istilah Spesifik per Section

Istilah yang sangat spesifik ke satu topik (misal nama upgrade tertentu di Hacker Points, atau nama rune tertentu di Realm 4) sebaiknya dijelaskan langsung di file section masing-masing, bukan di sini — glossary ini khusus untuk istilah yang dipakai lintas beberapa guide.
